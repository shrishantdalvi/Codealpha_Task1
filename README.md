
# Unemployment Analysis in India

## Project Overview

This project analyzes unemployment trends in India using data analysis and visualization techniques. The objective is to understand unemployment patterns over time, study the impact of COVID-19, and identify variations across different regions and areas.

## Dataset

The dataset contains unemployment-related information including:
- Region
- Date
- Frequency
- Unemployment Rate
- Employment Rate
- Labour Participation Rate
- Area (Urban/Rural)

## Data Cleaning & Transformation

The following preprocessing steps were performed:

- Removed extra spaces from column names.
- Renamed columns for better readability.
- Converted date values into datetime format.
- Checked and handled missing values.
- Removed duplicate records.
- Converted data types where required.

## Exploratory Data Analysis (EDA)

Performed analysis to identify trends and patterns:

- Time-based unemployment trend analysis.
- COVID-19 impact analysis.
- Region-wise unemployment comparison.
- Urban vs Rural unemployment analysis.
- Correlation analysis between economic indicators.

## Data Visualization

Created visualizations using:

- Line charts for time trends.
- Bar charts for regional comparison.
- Box plots for distribution analysis.
- Scatter plots and heatmaps for relationship analysis.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Jupyter Notebook

## Future Scope
